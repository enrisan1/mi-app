## Estado

**Cerrado en el alcance documentado.**

Este documento registra la evaluación reductiva de las dos primeras diferencias candidatas identificadas al comparar el estado alcanzado en T1 con `PLATFORM_VISION`:

```text
D-00 — Generalización operativa de la plataforma

D-01 — De trayectoria conocida
       a conjunto organizado de contenidos
```

```text
nueva Architecture

estructura documental
```

La finalidad es determinar si alguna de las dos diferencias contiene una pérdida funcional independiente que justifique una actuación posterior.

# 4. Regla reductiva

Una diferencia candidata sólo podrá justificar una actuación nueva si satisface conjuntamente:

```text
1. no está ya cubierta
   por una capacidad o investigación anterior;

2. describe una pérdida humana
   funcionalmente independiente;

3. puede aislarse
   de capacidades ya demostradas;

4. admite una prueba discriminante
   donde la variable causal pueda variar
   manteniendo constantes
   las capacidades de control;

5. su confirmación podría cambiar
   una decisión estratégica vigente.
```

Si cualquiera de estas condiciones falla:

```text
nueva capacidad
→ NO DERIVADA
```
