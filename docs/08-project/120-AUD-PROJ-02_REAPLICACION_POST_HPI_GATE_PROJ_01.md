# 8. GP-04 — relación explícita con Platform Vision

El problema de 97 no era la ausencia de implementación total de las seis familias, sino la falta de una clasificación explícita entre núcleo y evolución.

RED-PROJ-01 / F-PROJ-01 la establece:

| Familia | Núcleo material | Evolución posterior |
| --- | --- | --- |
| 4.1 evolución/estados | evolución textual + estado actual + antecedentes pertinentes | versionado/restauración/publicación formal |
| 4.2 organización/recuperación | recuperación básica + antecedentes + enriquecimiento contextual mínimo | organización/búsqueda/clasificación avanzada |
| 4.3 relaciones/reutilización | antecedente reconocible + reutilización + comparación | grafo/relaciones generales/descubrimiento |
| 4.4 transparencia | procedencia y distinción suficientes | evaluación crítica general |
| 4.5 colaboración/publicación | no bloqueante | evolución posterior |

4.5 queda explícitamente clasificada como no bloqueante para el primer umbral individual.

Esto no descarta colaboración/publicación ni afirma que carezcan de valor.
