# 1. Propósito

Este documento consolida la reevaluación y prueba mínima de:

```text
L-EXT-04
— Entidades del proyecto como objetos tipados
```

realizada después del cierre de:

```text
L-EXT-01
→ procedencia explícita y reconstrucción de trayectoria

L-EXT-02
→ anotación granular interoperable

L-EXT-03
→ Research Object portable
```

Su propósito consiste en determinar si, después de esas tres líneas, permanece una diferencia independiente y discriminable asociada a representar entidades propias del proyecto mediante estructuras tipadas y consultables.

La actuación no presupone:

```text
modelo general de objetos
ontología
knowledge graph
base de datos
RDF
JSON-LD
backend
API
Architecture
Implementation
```

La prueba se limita deliberadamente a una única entidad ya existente.

La actuación prescrita era:
