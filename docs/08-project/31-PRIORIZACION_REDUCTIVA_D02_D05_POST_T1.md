# Priorización reductiva comparativa de D-02, D-03, D-04 y D-05 después de T1

## Estado

**Cerrado en el alcance de priorización.**

Este documento registra la priorización reductiva comparativa de las diferencias todavía candidatas después del cierre de:

```text
30-REDUCCION_DIFERENCIAS_D00_D01_POST_T1.md
```

Las diferencias examinadas son:

```text
D-02 — Relaciones explorables
D-03 — Transparencia informativa
D-04 — Participación real sostenida
D-05 — Preservación duradera
```

La finalidad de esta actuación no es derivar una nueva capacidad, un nuevo hito del roadmap ni una nueva Realization.

Su objeto es determinar cuál de estas diferencias —si alguna— ofrece actualmente la formulación más limpia de una pérdida humana independiente y discriminable.

---

# 1. Regla de priorización

Cada diferencia se compara mediante cinco filtros:

```text
1. novedad;
2. irreducibilidad;
3. pérdida humana independiente;
4. discriminabilidad;
5. capacidad para cambiar una decisión estratégica.
```

Una diferencia no debe priorizarse por orden numérico, amplitud, atractivo funcional, sofisticación técnica o proximidad a una feature conocida.

# 2. D-02 — Relaciones explorables

`PLATFORM_VISION` contempla que las relaciones entre contenidos, actividades o contextos puedan facilitar:

```text
navegación
contextualización
descubrimiento
comparación
referencia
reutilización
trazabilidad
```

Sin embargo, el proyecto ya dispone de evidencia material sobre relaciones, participación, reutilización, procedencia, contexto y continuidad entre materiales.

La investigación sobre continuidad de participación entre materiales heterogéneos examinó pérdidas asociadas a relaciones y composición sin demostrar un residuo independiente respecto de compromisos ya consolidados.

La formulación:

```text
"relaciones explorables"
```

es todavía demasiado cercana a capacidades existentes.

Para sobrevivir como candidata nueva tendría que aislarse una situación del tipo:

```text
las relaciones existen
+
los contenidos son localizables
+
la reutilización es posible
↓
pero la persona pierde
una posibilidad pertinente
porque no puede recorrer,
descubrir o comparar
mediante esas relaciones
```

Esa pérdida adicional no está demostrada.

Resultado:

```text
D-02
→ REDUCCIÓN ADICIONAL NECESARIA
→ NO PRIORIZADA PARA PRUEBA INMEDIATA
```

# 3. D-03 — Transparencia informativa

`PLATFORM_VISION` contempla que la plataforma pueda proporcionar información que permita a las personas evaluar más informadamente procedencia, evolución, fundamentación y contexto.

El proyecto ya posee P3 — Publicación evaluable, por lo que no existe una diferencia nueva en la mera posibilidad de:

```text
criterio
+
evidencia
+
decisión humana
```

Sin embargo, puede aislarse una cuestión distinta:

```text
capacidad de evaluar
≠
disponibilidad de información pertinente
sobre cómo se constituyó aquello evaluado
```

La pérdida candidata puede formularse así:

> Una persona dispone de un resultado, puede leerlo, utilizarlo y ejercer su propio juicio, pero no puede determinar pertinentemente su procedencia o condiciones relevantes de constitución porque esa información no está disponible.

Esto permite mantener constantes:

```text
contenido
acceso
persistencia
lectura
uso
juicio humano
```

y variar únicamente:

```text
procedencia pertinente
→ disponible / no disponible
```

Resultado:

```text
D-03
→ NOVEDAD PLAUSIBLE
→ PÉRDIDA FORMULABLE
→ DISCRIMINABILIDAD ALTA
→ PRIORIDAD REDUCTIVA 1
```

---

# 4. Reducción interna de D-03

La expresión:

```text
D-03 — Transparencia informativa
```

continúa siendo demasiado amplia.

Se reduce provisionalmente a:

```text
D-03a — Disponibilidad de procedencia pertinente
```

Pregunta reductiva:

> Dado un resultado disponible, utilizable y susceptible de evaluación humana, ¿existe una pérdida específica cuando la información sobre su procedencia relevante deja de estar disponible, aunque el contenido mismo, su acceso y la capacidad humana de evaluarlo permanezcan intactos?

Esta formulación no presupone metadatos, autoría, historial, fuentes obligatorias ni modelo de procedencia.

# 5. D-04 — Participación real sostenida

`PLATFORM_VISION` contempla situaciones en las que varias personas participan en creación, revisión, enriquecimiento o difusión.

P4 ya ha realizado colaboración mínima.

Por tanto:

```text
"existe colaboración"
```

no constituye una diferencia nueva.

La formulación D-04 mezcla potencialmente pluralidad de personas, identidad, atribución, continuidad temporal, permisos, coordinación, conflictos y gobierno, y no constituye todavía una variable causal unitaria.

Además, investigaciones anteriores sobre agencia han mostrado que determinadas diferencias relativas a quién resolvió una decisión pueden quedar absorbidas por `PV-005 — Determinación humana efectiva`.

Resultado:

```text
D-04
→ POTENCIALMENTE NUEVA
→ PERO TODAVÍA AGREGADA
→ REQUIERE REDUCCIÓN FRENTE A PV-005
→ PRIORIDAD REDUCTIVA 2
```

# 6. D-05 — Preservación duradera

`PLATFORM_VISION` aspira a conservar lo necesario para que contenidos y contextos relevantes sigan siendo localizables, interpretables y utilizables a lo largo del tiempo.

Pero el proyecto ya ha ejercido persistencia, recuperación, continuidad, procedencia, interoperabilidad y preservación de posibilidades pertinentes.

La expresión:

```text
"duradera"
```

no basta para establecer una capacidad nueva.

Para aislar una diferencia adicional tendría que aparecer una situación en la que:

```text
persistencia ✓
recuperación ✓
localización ✓
posibilidades pertinentes ✓
procedencia básica ✓
```

y, aun así:

```text
el resultado deja de ser
interpretable o utilizable
por un cambio relevante
de contexto o condiciones
```

Ese residuo no está actualmente demostrado.

Resultado:

```text
D-05
→ FUERTE SOLAPAMIENTO CON PV-006
→ PÉRDIDA ADICIONAL NO AISLADA
→ PRIORIDAD REDUCTIVA 3
```
