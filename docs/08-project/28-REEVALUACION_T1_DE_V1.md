# 3. Regla metodológica de actualización

Para cada criterio se han distinguido cinco elementos:

```text
T0
+
evidencia original
+
evidencia posterior
+
efecto de la evidencia posterior
+
T1
```

La evidencia posterior no se considera automáticamente refuerzo.

Se utiliza:

```text
REFUERZA
```

cuando la evidencia posterior vuelve a ejercitar directamente el mismo criterio en un contexto posterior o más exigente sin alterar su alcance normativo.

Se utiliza:

```text
NO AFECTA DIRECTAMENTE
/
CONSERVA SIN CONTRADICCIÓN
```

cuando el trabajo posterior presupone, utiliza o permanece compatible con la capacidad, pero no vuelve a demostrar inequívocamente la estructura observable completa exigida por el criterio.

Para condiciones agregadas o globales puede utilizarse:

```text
REVALIDA
```

cuando la evidencia posterior amplía el conjunto de comportamiento auditado sin modificar el criterio normativo.

No se ha utilizado la categoría:

```text
EXTIENDE
```

porque ninguna evidencia posterior examinada obliga a ampliar los criterios normativos de V1.
