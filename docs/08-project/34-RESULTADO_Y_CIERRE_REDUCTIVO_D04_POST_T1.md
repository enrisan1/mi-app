# 1. Objeto de D-04

D-04 fue identificada provisionalmente como la diferencia:

```text
de colaboración demostrada
a participación real sostenida
```

Esta formulación era deliberadamente amplia.

Podía comprender, entre otros fenómenos:

```text
continuidad temporal
participación de materiales
participación de aportaciones
pluralidad de participantes
atribución
continuidad entre intervenciones
persistencia
decisión humana
colaboración
multiusuario real
sincronización
roles
permisos
```

No podía suponerse que todos estos elementos constituyeran una única necesidad humana.

Por tanto, D-04 debía ser sometida a reducción antes de derivar cualquier nueva capacidad.

---

# 2. Regla de reducción

Para que D-04 justificara un nuevo compromiso debía identificarse una pérdida humana que sobreviviera después de mantener suficientemente cubiertos:

```text
continuidad de materiales
continuidad de aportaciones
reutilización pertinente
determinación humana
pluralidad funcional de participantes
atribución
relación entre aportaciones
persistencia
reanudación
```

y que no pudiera reducirse a:

```text
PV-005
PV-006
P4
I29
R-INT-01
```

La mera ausencia de una tecnología o infraestructura concreta no constituye por sí misma una pérdida humana.

Por tanto:

```text
función no implementada
≠
necesidad humana demostrada
```
