# 4. Criterio discriminante

Un candidato sólo podrá clasificarse como residuo material pendiente cuando concurran simultáneamente:

```text
1. capacidad, relación o continuidad
   ya justificada;

2. existencia material
   efectivamente demostrada;

3. separación o participación insuficiente
   respecto del recorrido ordinario;

4. pérdida material real
   causada por esa separación;

5. insuficiencia actual
   no absorbida por cierres vigentes;

6. criterio verificable
   de reducción o cierre.
```

Si falta cualquiera de estos elementos, no podrá derivarse automáticamente una nueva construcción.
