# 🗺️ Roadmap del Producto

Este roadmap define la evolución del sistema hacia un producto SaaS completo.

---

## 🟢 Fase actual — Producción seed

✔ Store propio implementado  
✔ Reducer puro  
✔ Context como capa de integración  
✔ Persistencia local  
✔ Testing completo  
✔ CI/CD activo  
✔ Deploy en producción

---

## 🟡 Fase 2 — Escalado técnico

- Migración completa a TypeScript
- Optimización de rendimiento React
- Separación por dominios
- Mejora de arquitectura de estado

---

## 🔵 Fase 3 — Backend real

- API REST / GraphQL
- autenticación de usuarios
- persistencia en base de datos
- estado asíncrono

---

## 🟣 Fase 4 — Sistema avanzado

- Middleware en store
- Sistema de eventos interno
- Undo / Redo
- Observabilidad del estado

---

## 🔴 Fase 5 — Producto SaaS

- multiusuario
- permisos y roles
- métricas de uso
- logging avanzado
- escalado horizontal
