# TH-80-02-05 — Contraste humano de composición M5 + M6 en textos largos

**Fecha de apertura:** 16/11/2026  
**Estado:** prerregistrado; ejecución humana pendiente.  
**Composición:** `R-80-02-M5 — marcado inline neutral` + `R-80-02-M6 — paneles laterales independientes`.  
**Pregunta:** si la composición mejora materialmente la comparación de textos extensos sin introducir nuevas fricciones relevantes.

---

# 1. Hipótesis

`H-TH-80-02-05`:

> Para dos documentos extensos con diferencias literales distribuidas, presentar
> ambos en paneles laterales independientes con marcado inline permite comparar
> los cambios manteniendo orientación y copresencia suficientes, sin relocalización
> manual material ni necesidad frecuente de realinear ambos paneles.

---

# 2. Falsadores

La hipótesis queda debilitada o refutada si ocurre materialmente alguno de estos casos:

1. la persona pierde con frecuencia qué fragmentos está comparando;
2. necesita desplazar repetidamente ambos paneles sólo para recuperar correspondencia;
3. el scroll independiente produce desalineación que dificulta más de lo que ayuda;
4. el marcado inline genera saturación visual material;
5. la lateralidad reduce demasiado el ancho de lectura;
6. la persona preferiría volver a una disposición vertical para textos extensos;
7. se necesita navegación/sincronización para que la comparación sea realmente practicable.

---

# 3. Observables

`O1` — copresencia real durante la comparación.  
`O2` — orientación dentro de ambos documentos.  
`O3` — necesidad de realineación manual entre paneles.  
`O4` — carga visual de las marcas.  
`O5` — claridad de correspondencia D1/D2.  
`O6` — comodidad de lectura con dos columnas.  
`O7` — necesidad percibida de navegación o sincronización adicional.  
`O8` — comparación cualitativa frente a la experiencia vertical previa.

---

# 4. Materiales

Se utilizarán dos documentos nuevos, D1-L2 y D2-L2, suficientemente extensos para
exigir desplazamiento interno de ambos paneles.

Las diferencias estarán distribuidas a lo largo de los textos.

La persona no recibirá previamente:

- número de diferencias;
- localización exacta;
- relevancia;
- ni orden esperado.

---

# 5. Regla de ejecución

La persona deberá trabajar sólo con la superficie lateral marcada.

Podrá desplazar cada panel de forma independiente.

No habrá:

- sincronización automática;
- navegación siguiente/anterior;
- lista separada de detecciones;
- edición;
- relevancia;
- ni recomendación.

La persona deberá observar especialmente si necesita mover ambos paneles de forma
repetitiva para volver a alinear fragmentos relacionados.

---

# 6. Resultado posible

```text
A — SUFICIENCIA MATERIAL
→ lateralidad + marcado inline hacen practicable la comparación extensa

B — MEJORA PARCIAL
→ mejoran materialmente, pero sobrevive una fricción estructural relevante

C — INSUFICIENTE
→ la composición no evita pérdida de orientación o realineación material
```

---

# 7. Límite

Este contraste no evalúa:

- semántica;
- edición;
- aceptación/rechazo;
- sincronización automática;
- navegación;
- ni responsive.
