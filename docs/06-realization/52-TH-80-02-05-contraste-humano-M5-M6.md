# TH-80-02-05 — Contraste humano de composición M5 + M6 en textos largos

**Fecha de apertura:** 16/11/2026  
**Estado:** prerregistrado; ejecución humana pendiente.  
**Composición:** `R-80-02-M5 — marcado inline neutral` + `R-80-02-M6 — paneles laterales independientes`.  
**Pregunta:** si la composición mejora materialmente la comparación de textos extensos sin introducir nuevas fricciones relevantes.

---

# 1. Hipótesis

`H-TH-80-02-05`:

> Para dos documentos extensos con diferencias literales distribuidas, presentar
> ambos en paneles laterales independientes con marcado inline permite comparar
> los cambios manteniendo orientación y copresencia suficientes, sin relocalización
> manual material ni necesidad frecuente de realinear ambos paneles.

---

# 2. Falsadores

La hipótesis queda debilitada o refutada si ocurre materialmente alguno de estos casos:

1. la persona pierde con frecuencia qué fragmentos está comparando;
2. necesita desplazar repetidamente ambos paneles sólo para recuperar correspondencia;
3. el scroll independiente produce desalineación que dificulta más de lo que ayuda;
4. el marcado inline genera saturación visual material;
5. la lateralidad reduce demasiado el ancho de lectura;
6. la persona preferiría volver a una disposición vertical para textos extensos;
7. se necesita navegación/sincronización para que la comparación sea realmente practicable.

---

# 3. Observables

`O1` — copresencia real durante la comparación.  
`O2` — orientación dentro de ambos documentos.  
`O3` — necesidad de realineación manual entre paneles.  
`O4` — carga visual de las marcas.  
`O5` — claridad de correspondencia D1/D2.  
`O6` — comodidad de lectura con dos columnas.  
`O7` — necesidad percibida de navegación o sincronización adicional.  
`O8` — comparación cualitativa frente a la experiencia vertical previa.

---

# 4. Materiales

Se utilizarán dos documentos nuevos, D1-L2 y D2-L2, suficientemente extensos para
exigir desplazamiento interno de ambos paneles.

Las diferencias estarán distribuidas a lo largo de los textos.

La persona no recibirá previamente:

- número de diferencias;
- localización exacta;
- relevancia;
- ni orden esperado.

---

# 5. Regla de ejecución

La persona deberá trabajar sólo con la superficie lateral marcada.

Podrá desplazar cada panel de forma independiente.

No habrá:

- sincronización automática;
- navegación siguiente/anterior;
- lista separada de detecciones;
- edición;
- relevancia;
- ni recomendación.

La persona deberá observar especialmente si necesita mover ambos paneles de forma
repetitiva para volver a alinear fragmentos relacionados.

---

# 6. Resultado posible

```text
A — SUFICIENCIA MATERIAL
→ lateralidad + marcado inline hacen practicable la comparación extensa

B — MEJORA PARCIAL
→ mejoran materialmente, pero sobrevive una fricción estructural relevante

C — INSUFICIENTE
→ la composición no evita pérdida de orientación o realineación material
```

---

# 7. Límite

Este contraste no evalúa:

- semántica;
- edición;
- aceptación/rechazo;
- sincronización automática;
- navegación;
- ni responsive.


---

# 8. Ejecución humana

**Fecha:** 16/11/2026

## 8.1. Observación

La persona informó:

- ambos textos pueden mantenerse presentes simultáneamente;
- la orientación inicial y media resulta suficiente;
- las marcas inline —las marcas visuales situadas dentro del propio texto, en
  este testigo mediante cambio de color— permiten reconocer directamente las
  diferencias;
- en una fase avanzada del recorrido aparece pérdida de orientación global;
- la sensación descrita es la de perder referencias sobre “dónde se está” dentro
  del conjunto del documento;
- se percibe necesidad de algún apoyo adicional de navegación o sincronización.

## 8.2. Resultado del caso

```text
TH-80-02-05
→ B — MEJORA PARCIAL

M5 + M6
→ mejora materialmente copresencia y localización

pero

recorrido avanzado
→ pérdida de referencia global
→ necesidad de apoyo adicional de orientación/navegación
```

No se observa fallo del marcado inline ni de la lateralidad básica.

La fricción residual aparece después de que ambos mecanismos ya estén funcionando.

---

# 9. Reducción de la fricción residual

Se deriva provisionalmente:

`PC-80-02-06 — Referencia de posición comparativa durante el recorrido`.

Formulación:

> Durante la comparación de documentos extensos, la persona conserva una
> referencia suficiente de dónde se encuentra en cada fuente y puede recuperar
> rápidamente el siguiente punto de comparación sin perder orientación global.

Esta propiedad no prescribe todavía:

- scroll sincronizado continuo;
- navegación siguiente/anterior;
- minimapa;
- numeración de secciones;
- barra de progreso;
- anclas;
- ni sincronización al activar una detección.

---

# 10. Hipótesis de mecanismos

Quedan abiertas al menos tres familias:

## A — navegación entre detecciones

```text
anterior ← detección actual → siguiente
```

Ventaja:
- ofrece referencia discreta de progreso;
- reduce búsqueda del siguiente cambio.

Riesgo:
- puede estrechar el foco demasiado y ocultar contexto global.

## B — sincronización al activar una detección

```text
activar detección
→ ambos paneles se posicionan en los fragmentos correspondientes
→ después continúan independientes
```

Ventaja:
- conserva independencia;
- recupera correspondencia cuando se pierde.

Riesgo:
- necesita posiciones/rangos fiables.

## C — referencia estructural de posición

Ejemplos posibles:

- sección actual;
- ordinal de detección;
- indicador de progreso;
- minimapa;
- anclas discretas.

Ventaja:
- ataca directamente la pérdida de orientación global.

Riesgo:
- algunas variantes pueden añadir mucha interfaz sin reducir realmente trabajo.
