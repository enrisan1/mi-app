## 2. Fundamento de apertura

Las dos primeras aplicaciones de `POU-RU2M1-01` permitieron obtener evidencia real de uso.

Durante la preparación de `OU-RU2M1-002` apareció además una cuestión preobservacional: la ejecución inicialmente utilizada conservaba un `X` válido restaurado procedente de una aplicación anterior.

La investigación posterior estableció que una ejecución destinada a constituir `S1` debe comenzar:

```text
sin X válido restaurado
```

La condición fue incorporada documentalmente a `POU-RU2M1-01` y a su ficha mínima de observación.

La revisión documental no proporciona por sí misma evidencia de que el protocolo revisado resulte instrumentalmente suficiente en una nueva aplicación.

La estrategia vigente del proyecto selecciona ahora una nueva aplicación formal como fuente deliberada de evidencia de uso.

Por tanto:

```text
POU-RU2M1-01 revisado
+
R-U2-M1 destinada al uso
+
decisión estratégica de obtener nueva evidencia
↓
OU-RU2M1-003
```

Este fundamento justifica la observación.

No justifica anticipadamente ninguna investigación posterior.
