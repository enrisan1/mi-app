# 3. Multiplicidad física detectada en el corpus

La inspección contextual de las multiplicidades recuperadas mostró que la igualdad textual no era suficiente para determinar si una aparición era documentalmente prescindible.

Durante la investigación aparecieron, al menos, situaciones distintas:

```text
duplicación de regiones documentales extensas
+
recomposición de material previo
+
copia utilizada para conservar clasificación
+
copia utilizada para conservar estado documental
+
mismo contenido empleado en contextos distintos
```

Por ello, las coordenadas históricas deben distinguirse siempre de las coordenadas resultantes después de cada depuración física.

# 10. Regla de modificación

La depuración realizada mostró que la igualdad textual puede corresponder a situaciones documentales diferentes.

Antes de eliminar una aparición repetida deberá comprobarse:

```text
igualdad textual
+
posición
+
contexto
+
procedencia
+
función documental
+
estado documental
+
pluralidad contextual
+
posible pertenencia a una duplicación mayor
```

Por tanto:

```text
texto idéntico
≠ eliminación automática
```

y:

```text
duplicado local
≠ necesariamente problema local
```

También:

```text
igualdad textual
+
contextos diferentes
→ puede justificar conservación múltiple
```

y:

```text
igualdad textual
+
clasificación distinta
→ puede conservar información

igualdad textual
+
estado documental distinto
→ puede conservar información
```

La investigación mostró tres mecanismos distintos.

### Duplicación estructural prescindible

```text
misma región sustantiva
+
sin aportación exclusiva relevante
→ reducción posible
```

### Copia que conserva clasificación o estado

```text
mismo contenido
+
posición funcional distinta
→ no eliminar automáticamente
```

### Pluralidad contextual

```text
mismo contenido
+
uso efectivo en dos configuraciones distintas
→ ambas apariciones pueden ser necesarias
```

La edición sólo se realizará después de una decisión humana explícita.
