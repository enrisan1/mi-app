## 4.7. Resultado metodológico local

La inspección mostró que una multiplicidad detectada por recuperación puede corresponder no sólo a:

```text
repetición de un párrafo
```

sino también a:

```text
duplicación de una región documental extensa
```

Por ello:

```text
duplicado recuperado
→ inspección contextual
→ búsqueda de estructura mayor
→ reducción de la causa común
```

resulta preferible, cuando existe fundamento, a:

```text
duplicado recuperado
→ eliminación aislada del párrafo
```

Este resultado es local al corpus observado y no establece una regla universal sobre cualquier documento.

# 7. Regla de modificación

Antes de eliminar una aparición textual repetida deberá comprobarse:

```text
igualdad textual
+
posición
+
contexto
+
procedencia
+
función documental
+
posible pertenencia a una duplicación mayor
```

Por tanto:

```text
texto idéntico
≠ eliminación automática
```

y también:

```text
duplicado local
≠ necesariamente problema local
```

La edición sólo se realizará después de una decisión humana explícita.
