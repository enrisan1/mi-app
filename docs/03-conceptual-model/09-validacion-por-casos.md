# 09 Validación por casos

# Validación por casos

## Propósito

Este documento somete el estado consolidado de la teoría conceptual a casos concretos y heterogéneos.

Su finalidad consiste en comprobar si los resultados actualmente aceptados permiten conservar los contrastes pertinentes de los casos sin necesidad de:

- restaurar fenómenos universales irreducibles;
- restaurar exigencias estructurales universales positivas;
- restaurar un perfil funcional universal;
- restaurar una firma conceptual universal;
- restaurar axiomas sustantivos universales;
- restaurar un régimen universal positivo de especialización;
- o ampliar silenciosamente categorías metalingüísticas hasta convertirlas en nuevas primitivas.

La validación no pretende demostrar que la teoría sea verdadera.

Pretende proporcionar oportunidades concretas de falsación.

# Qué significa validar

Un caso no queda validado porque pueda describirse utilizando libremente cualquier recurso.

La validación debe comprobar si:

1. los contrastes relevantes del caso pueden formularse;
2. no se pierde información necesaria;
3. los recursos positivos utilizados pueden localizarse legítimamente;
4. ninguna decisión local se promueve indebidamente a universal;
5. ninguna categoría histórica eliminada se restaura sin justificación;
6. no aparece una pérdida que obligue a reabrir algún resultado consolidado.

Por tanto:

```text
describir un caso
≠
validarlo.
```

---

# Estados de validación

Cada caso podrá terminar en uno de tres estados.

## `PASS`

Los contrastes pertinentes pueden conservarse sin falsar ningún resultado consolidado.

```text
PASS
```

no significa:

```text
caso explicado definitivamente.
```

Significa únicamente:

> el caso no proporciona actualmente un falsador suficiente.

---

## `FAIL`

Aparece una pérdida concreta no reconstruible bajo el estado consolidado.

Debe especificarse:

```text
qué contraste se pierde;
qué resultado queda falsado;
qué documento debe reabrirse.
```

---

## `OPEN`

La información disponible no permite decidir la prueba sin importar supuestos adicionales.

`OPEN` no deberá tratarse como `PASS`.

---

# Regla contra la validación retrospectiva

Los casos utilizados históricamente por versiones anteriores de la teoría no conservan automáticamente sus antiguos veredictos.

En particular, no se importan cadenas históricas basadas en:

```text
P
S
V
R
Φ
CE
TV

CAN-F1
CAN-F2
CAN-F3

P-001
MA-001
MA-002.
```

Cada caso se vuelve a examinar desde el estado consolidado actual.

# `C-001 — Libro`

## Problema

«Libro» puede utilizarse para hablar de cosas diferentes:

- obra;
- edición;
- ejemplar;
- objeto físico;
- contenido;
- miembro de una colección;
- objeto descrito por metadatos.

La prueba no deberá asumir que todas ellas son entidades de una misma sorte.

---

## `VC-1 — Contrastes`

Deben poder distinguirse, cuando la cuestión lo requiera:

```text
obra
≠
edición
```

```text
edición
≠
ejemplar
```

```text
ejemplar físico
≠
representación técnica
del ejemplar
```

```text
libro considerado
≠
conocimiento producido
al interpretarlo.
```

---

## `VC-2 — Localización`

Una especialización bibliográfica puede introducir localmente:

```text
TipoObra
TipoEdición
TipoEjemplar
```

y relaciones entre ellos.

Su necesidad pertenece a esa especialización.

No al núcleo universal.

---

## `VC-3 — Necesidad universal`

El caso no demuestra que **todo** dominio necesite:

```text
obra
edición
ejemplar
```

ni una categoría universal de identidad.

---

## `VC-4 — Especialización local`

La estructura bibliográfica positiva puede justificarse localmente por las preguntas que deba responder la especialización:

- qué ejemplar posee una biblioteca;
- qué edición materializa una obra;
- qué ejemplares pertenecen a una edición.

---

## `VC-5 — Reintroducción encubierta`

No es necesario restaurar:

```text
P-001
CAN-F1
S
```

para distinguir estas categorías localmente.

---

## `VC-6 — Pérdida`

No se identifica pérdida si las discriminaciones se justifican dentro de la especialización bibliográfica.

---

## Resultado

```text
C-001 — PASS
```

No falsifica:

```text
Σ_min = ∅
Ax_min = ∅
RE_universal_positivo = ∅.
```

# Validación específica de especializaciones

Los casos muestran repetidamente la misma posibilidad:

```text
especialización local
+
estructura positiva local
```

es compatible con:

```text
núcleo universal positivo vacío.
```

Ejemplos:

```text
bibliografía
→ Obra / Edición / Ejemplar

numismática
→ Pieza / Tipo / Emisión

sensores
→ Sensor / Observación / Valor

traducción
→ Fuente / Meta / Segmento
```

Estas estructuras no necesitan coincidir entre sí.

---

# Prueba de no universalización

Debe comprobarse si la recurrencia de ciertas formas locales obliga a restaurar categorías universales.

Por ejemplo, numerosos casos utilizan localmente:

```text
algún criterio de distinción
alguna relación
algún orden
algún identificador
```

Pero:

```text
recurrencia de recursos locales
⇏
primitiva universal.
```

La recurrencia sólo podría generar una nueva hipótesis.

Para justificar universalidad todavía sería necesario demostrar:

```text
pérdida
+
irreducibilidad
+
nivel correcto
+
estabilidad global.
```

No aparece esa demostración en los diez casos.

---

# Prueba de diversidad

Los casos también muestran que las especializaciones pueden requerir estructuras muy diferentes.

```text
Libro
→ obra / edición / ejemplar

Fósil
→ espécimen / clasificación / medida

Conversación
→ turnos / interlocutores / orden

Sensor
→ observaciones / unidades / valores

Traducción
→ fuente / meta / correspondencias

Resumen
→ fuente / finalidad / selección.
```

No emerge una única estructura positiva común que conserve contenido específico suficiente para justificar una primitiva universal.

---

# Prueba de propiedad emergente global

Aunque cada caso individual sea compatible con el resultado vacío, podría ocurrir que los diez conjuntamente exigieran alguna categoría universal.

Se examinan posibles candidatos:

```text
identidad
relación
orden
unidad
procedencia
derivación
interpretabilidad
representación.
```

La consideración conjunta no demuestra que ninguno de ellos requiera estatuto universal positivo.

Cada aparición puede localizarse mediante:

- criterios locales;
- estructuras especializadas;
- relaciones concretas;
- representación;
- actividad interpretativa externa;
- realización técnica.

Por tanto:

```text
propiedad emergente universal
detectada por C-001…C-010
=
ninguna.
```

---

# Prueba de antiinflación

El éxito de los casos no puede conseguirse diciendo simplemente:

```text
“cada caso puede usar
lo que necesite”.
```

Eso trivializaría la validación.

Una especialización local deberá justificar sus recursos respecto de sus propias preguntas y contrastes.

Por ejemplo:

```text
TipoEjemplar
```

es legítimo sólo si realiza un trabajo concreto en la especialización bibliográfica.

No porque cualquier especialización tenga permiso ilimitado para introducir categorías.

Por tanto:

```text
libertad local
≠
arbitrariedad local.
```

# Prueba de frontera con interpretación

Varios casos tensionan la distinción entre configuración e interpretación:

```text
fotografía;
fósil;
sensor;
traducción;
crítica;
nota.
```

El corpus histórico ya hacía explícita esta separación en casos como fotografía y sensor.
Ninguno obliga a tratar:

```text
interpretación del agente
```

como operación conceptual interna universal.

La teoría puede registrar:

- resultados;
- afirmaciones;
- relaciones;
- productos;

sin constituir internamente el acto cognoscitivo que los originó.

---

# Prueba de frontera física/técnica

Libro, fósil, moneda y fotografía muestran que debe poder distinguirse entre:

```text
objeto físico
```

y:

```text
representación,
registro,
descripción
o especialización conceptual.
```

La persistencia de un registro no constituye por sí sola identidad conceptual.

La multiplicidad de copias tampoco determina multiplicidad conceptual.

No se detecta falsador para las fronteras actualmente consolidadas.

---

# Prueba de procedencia

Fósil, traducción y resumen muestran que pueden ser necesarias relaciones locales de:

```text
origen;
fuente;
dependencia;
producción.
```

Esto no obliga a una relación universal:

```text
Prov.
```

La procedencia sigue siendo reconstruible mediante relaciones y criterios particulares.

---

# Prueba de correspondencia

Traducción introduce correspondencias locales entre segmentos.

Esto no obliga a:

```text
Corr
```

como relación universal uniforme.

El caso confirma que:

```text
correspondencia local
≠
Correspondencia universal.
```

# Prueba de identidad

Libro, fósil, moneda y nota pueden necesitar criterios locales de «mismo».

Pero los criterios difieren.

No aparece una función universal independiente que deba decidir todos los casos.

Por tanto no se detecta falsador para la eliminación de `CAN-F1`.

Pero la necesidad de una representación relacional adecuada no implica:


como capacidad conceptual universal.

No aparece falsador.

# Criterio para añadir un nuevo caso

Un nuevo caso deberá aportar al menos una de estas posibilidades:

1. contraste no cubierto por los casos existentes;
2. presión sobre una frontera de nivel;
3. posible necesidad de nueva estructura universal;
4. conflicto entre especializaciones;
5. dificultad de localización conceptual/técnica;
6. posible propiedad emergente;
7. falsador de alguna conclusión vigente.

La mera diversidad temática no basta.
